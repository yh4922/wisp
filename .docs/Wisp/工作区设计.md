# 工作区（M4）与 SSH 远程（M5）设计

## 数据模型

文件：`<config_dir>/workspaces.json`（Windows 为 `%APPDATA%\Wisp\workspaces.json`）

```json
{
  "version": 1,
  "hosts": [
    {
      "id": "uuid",
      "name": "测试服务器",
      "host": "192.168.1.10",
      "port": 22,
      "username": "root",
      "auth": "password",
      "key_path": null
    }
  ],
  "workspaces": [
    { "id": "uuid", "name": "我的项目", "kind": "local", "path": "D:\\Project\\Foo", "last_opened_at": "2026-11-24T00:00:00Z" },
    { "id": "uuid", "name": "线上服务", "kind": "remote", "host_id": "uuid", "path": "/srv/app", "last_opened_at": null }
  ]
}
```

- `auth`: `password` | `key`。`key` 时 `key_path` 为私钥路径。
- 密码 / 私钥口令不进 JSON，存系统凭据管理器（`credentials_provider`），key 为 `wisp-host://<host_id>`，Windows 下为 Credential Manager 条目。
- 「最近打开」直接复用 workspace 数据库中的最近项目（本地 + 远程），可一键「保存为工作区」。

## crate 划分

| crate | 职责 |
|---|---|
| `wisp_workspaces` | 数据模型、读写 `workspaces.json`（原子写入 + 变更通知 gpui Global）、凭据读写 API |
| `workspace_panel` | 侧边栏「工作区」面板（Panel，默认左侧 dock）+ 启动页工作区区块 + 新建/编辑弹窗 |
| `recent_projects`（复用）| 远程连接：`RemoteConnectionOptions::Ssh`，把保存的密码 / 私钥注入连接 |

## 交互

- 启动页（welcome / launchpad）：顶部「打开本地文件夹」「打开远程」按钮；下方「已保存的工作区」卡片网格（图标区分本地/远程，显示备注名 + 路径 / user@host），再下方「最近打开」。
- 侧边栏面板：同样两组列表 + 顶部「+」菜单（添加本地工作区 / 添加远程工作区 / 管理主机）。
- 条目操作：单击打开（替换当前窗口），Ctrl+单击新窗口；右键菜单：在新窗口打开、重命名、编辑、删除。
- 打开本地：系统文件夹选择器 → 弹出命名框（默认文件夹名）→ 保存并打开。
- 打开远程：选择已有主机或新建主机（备注名、IP、端口默认 22、用户名、认证方式：密码 / 私钥路径 + 口令）→ 测试连接 → 浏览远程目录（顶部路径输入框 + 目录列表，可逐级进入）→ 命名 → 保存并打开。
