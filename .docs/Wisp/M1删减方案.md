# M1 删减方案

## 关键结论

`client`、`telemetry`、`http_client`、`dap`、`auto_update`（下载 remote server 逻辑）、`edit_prediction_types` 被核心 crate 深度使用，**不直接删**：保留精简 crate，只去掉 UI 与网络调用。

## 分批（每批独立编译通过）

1. **叶子 crate**：repl、vim（保留 vim_mode_setting）、collab、collab_ui、feedback、auto_update_ui、debugger_ui、debugger_tools、acp_tools、extensions_ui、extension_suggest、extension_cli、theme_extension、edit_prediction_cli、eval_cli、agent_ui_benchmarks、hang_telemetry、sidebar、onboarding/language_onboarding、zed_* 测试扩展；同步改 zed.rs、main.rs、app_menus、keymap。
2. **AI 前端**：agent_ui、agent、acp_thread、agent_servers、action_log、edit_prediction*、copilot*、codestral、language_models 及全部 provider、web_search*；settings_ui AI 页、git_ui AI 提交信息、终端 inline assist、language_tools 引用、edit_prediction_registry。
3. **AI 基础**：agent_settings、language_model*、prompt_store、context_server、oauth_callback_server；project 的 context_server_store / agent_*_store；settings_content agent/language_model；default.json 与 keymap AI 项。
4. **扩展系统**：extension_host、extension、language_extension、debug_adapter_extension；改 project、remote_server、recent_projects、activity_indicator、json_schema_store、snippet_provider。
5. **协作与云**：call、channel、livekit*、audio、cloud_api_*；精简 client（去登录、LLM token、遥测上报），telemetry 宏改空实现，清理 title_bar；remote server 下载逻辑迁出 auto_update 后删 auto_update、crashes。
6. **调试器内部（可选）**：dap_adapters，再评估 dap 与 project::debugger、编辑器断点。
7. **收尾（可选）**：editor/src/edit_prediction.rs 与 edit_prediction_types；vim_mode_setting 空壳。

每批后：`cargo check -p zed -p remote_server`。

## 副作用

删除扩展系统后，仅靠扩展提供的语言（HTML、PHP 等）失去支持 → 需在 `languages` crate 内置（Q15 清单）。
