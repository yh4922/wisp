# Wisp 需求文档

> 基于 Zed v1.29.3 硬分叉的轻量代码编辑器。开源仓库：https://github.com/yh4922/wisp（GPL-3.0）

## 1. 定位

只保留「编辑器 + 终端 + SSH 远程」的桌面代码编辑器，去除 AI、插件市场、云账号与协作。

## 3. 功能需求

### 3.1 工作区

- 打开本地：系统文件夹选择器 → 打开，可保存为工作区（备注名）。
- 打开远程：选择/新建主机（备注名、IP、端口默认 22、用户名、认证方式：密码 / 私钥路径+口令）→ 连接 → 浏览远程目录 → 打开，可保存为工作区。
- 列表：已保存工作区（本地/远程图标区分，显示备注名与路径/主机）、最近打开；支持重命名、删除、编辑主机。
- 数据：`%APPDATA%\Wisp\workspaces.json`；密码/口令仅存 Windows 凭据管理器。

### 3.2 国际化

- 语言设置：`"ui_language": "system" | "zh-CN" | "en"`。
- 未翻译文案回退英文。
